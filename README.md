### Требования
Для запуска и разработки проекта вам понадобятся:

* **Python 3.14+** (проект использует современные возможности типизации)
* **Poetry** — инструмент для управления зависимостями и виртуальными окружениями.


### Настройка окружения и зависимостей
В этом проекте для управления зависимостями используется **Poetry**. Убедитесь, что он [установлен](https://python-poetry.org) в вашей системе.

### 1. Клонирование репозитория
```bash
git clone https://github.com/alexsvch-log/homework.git
```

### 2. Установка зависимостей
Эта команда автоматически создаст виртуальное окружение и установит все необходимые пакеты, указанные в `pyproject.toml`:

```bash
poetry install
```

### 3. Активация окружения (опционально)
Чтобы запустить команды внутри созданного окружения, используйте:
```bash
poetry shell
```
Или запускайте скрипты напрямую через `poetry run`:
```bash
poetry run python main.py
```
Файл requirements.txt отсутствует, так как зависимости полностью управляются через pyproject.toml.


### Инструменты разработки (Linting)
Для установки инструментов проверки кода (black, flake8 и др.) используйте:
```bash
poetry install --with lint
```
Если вы планируете использовать линтер flake8, то рекомендуется установить плагин командой **poetry add flake8-pyproject**.
Файл .flake8 в проекте отсутствует.

В случае, если вы решите установить линтеры - black, flake8, mypy - в корне проекта расположен файл lint.bat. При выполнении команды: .\lint на терминале запускаются все линтеры сразу.


## Использование

Проект разделен на три основных модуля.
Сначала активируйте окружение через `poetry shell`, затем используйте функции в своих скриптах или через интерактивную оболочку Python.

### 1. Модуль `masks`
Модуль реализует две функции:
* Функцию маскировки номера банковской карты: get_mask_card_number.
Функция  принимает на вход номер карты и возвращает ее маску. Номер карты замаскирован и отображается в формате
    XXXX XX** **** XXXX, где X — это цифра номера. То есть видны первые 6 цифр и последние 4 цифры, остальные символы
    отображаются звездочками, номер разбит по блокам по 4 цифры, разделенным пробелами.

* Функцию маскировки номера банковского счета: get_mask_account.
Функция принимает на вход номер счета и возвращает его маску. Номер счета замаскирован и отображается в формате
    **XXXX, где X — это цифра номера. То есть видны только последние 4 цифры номера, а перед ними — две звездочки.

```python
from src.masks import get_mask_card_number, get_mask_account

# Пример вызова первой функции
result_1 = get_mask_card_number("7000792289606361")
# result_1 = "7000 79** **** 6361"

# Пример вызова второй функции
result_2 = get_mask_account("73654108430135874305")
# result_2 = "**4305"
```

### 2. Модуль `widget`
* Модуль содержит функции для работы с новыми возможностями приложения:
* Функцию маскировки номера банковской карты и счета: mask_account_card.
Функция обрабатывает информацию как о картах, так и о счетах. Принимает один аргумент — строку, содержащую тип
    и номер карты или счета. Возвращает строку с замаскированным номером.
Функция использует импорт следующих функций из модуля 'masks':
* get_mask_card_number
* get_mask_account

* Функцию обработки данных содержащих дату в формат ДД.ММ.ГГГГ: get_date.
Функция принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407" и возвращает строку с датой
    в ISO формате "ДД.ММ.ГГГГ" ("11.03.2024").
* Функция использует импорт функции datetime.


```python
from src.widget import mask_account_card, get_date

# Пример вызова первой функции
result_1 = mask_account_card("Maestro 1596837868705199")
# result_1 = "Maestro 1596 83** **** 5199"

# Пример вызова второй функции
result_2 = get_date("2024-03-11T02:26:18.671407")
# result_2 = "11.03.2024"
```

### 3. Модуль `processing`
* Модуль содержит новые функции обработки данных:
* Функцию фильтрации транзакций по заданному ключу 'state': filter_by_state.
Функция принимает словарь с транзакциями и выбирает только те транзакции,
    которые заданы в ключе state (по умолчанию значение state = 'EXECUTED').

* Функцию сортировки транзакций по дате в порядке возрастания либо убывания в зависимости от заданного параметра: sort_by_date.
Функция принимает список словарей с транзакциями и возвращает список словарей с транзакциями,
    отсортированными по дате (ключ 'date').

```python
from src.processing import filter_by_state, sort_by_date

result_1 = filter_by_state(

# result_1 = [

#         {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"},
```

## Тестирование и покрытие (Coverage)

Проект управляется с помощью **Poetry**. Все тестовые модули изолированы друг от друга и проверяют конкретный функционал из папки `src`.

### Подготовка к тестированию
Перед запуском убедитесь, что установлены все зависимости и плагин для расчета покрытия (`pytest-cov`):
```bash
poetry install
```
*(Если плагин еще не добавлен в проект, установите его командой: `poetry add pytest-cov --group dev`)*

### Запуск тестов

* **Запуск всех тестов:**
  ```bash
  poetry run pytest
  ```
* **Помодульный запуск:**
  ```bash
  poetry run pytest test/test_mask.py
  poetry run pytest test/test_widget.py
  poetry run pytest test/test_processing.py
  ```

### Анализ покрытия кода (Coverage)

Чтобы проверить, насколько хорошо тесты покрывают код в папке `src`, используйте следующие команды:

1. **Вывод отчета прямо в терминал:**
   ```bash
   poetry run pytest --cov=src
   ```

2. **Генерация подробного HTML-отчета:**
   ```bash
   poetry run pytest --cov=src --cov-report=html
   ```
   После выполнения команды в корне проекта появится папка `htmlcov/`. Откройте файл `htmlcov/index.html` в любом браузере, чтобы увидеть, какие строки кода остались не протестированы.

### Конфигурация тестов
Файл `test/conftest.py` содержит общие фикстуры для генерации данных, которые автоматически подтягиваются при расчете покрытия.
